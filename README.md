# คืนลอยกระทง

เว็บลอยกระทงภาษาไทย เล่นคนเดียวหรือชวนเพื่อนเข้าห้องเดียวกันได้สูงสุด 4 คน รวมคนเปิดห้อง เลือกกระทงได้ 3 แบบ กดที่กระทงเพื่ออ่านคำอธิษฐานที่เจ้าของเลือกแชร์

## ขึ้น GitHub Pages

1. สร้าง repository ชื่อ `loy-krathong` ในบัญชี GitHub ของคุณ ถ้าใช้ GitHub Free ให้เลือก Public
2. นำไฟล์ **ด้านใน** โฟลเดอร์นี้ขึ้น branch `main` ให้ `index.html` อยู่ที่ราก repository และเก็บ `assets/river.webp` ไว้ในโฟลเดอร์ `assets`
3. เข้า **Settings → Pages** เลือก **Deploy from a branch** แล้วเลือก **main → / (root)** และกด **Save**
4. เปิดลิงก์ที่ GitHub แสดงในหน้า Pages จากนั้นกด **ชวนเพื่อน → สร้างห้อง → คัดลอกลิงก์**

คู่มือ [GitHub Pages](https://docs.github.com/en/pages/quickstart)

## เล่นในเครื่อง

เปิดเทอร์มินัลในโฟลเดอร์นี้แล้วรัน

```sh
python -m http.server 8000 --bind 127.0.0.1
```

เปิด [localhost:8000](http://localhost:8000/) ในเบราว์เซอร์ หากจะทดสอบห้องบนเครื่องเดียวกัน ให้เปิดลิงก์เชิญในอีกแท็บ

## การทำงานของห้อง

- เว็บใช้ HTML, CSS และ JavaScript เปิดผ่าน GitHub Pages ได้โดยไม่ต้องบิลด์ ห้องใช้ [PeerJS Cloud](https://peerjs.com/client/faq) เพื่อเชื่อมเบราว์เซอร์ด้วย WebRTC บางเครือข่ายอาจเชื่อมต่อไม่ได้
- คนสร้างห้องต้องเปิดแท็บไว้ หากปิดหรือรีเฟรช ห้องและรายการกระทงของห้องนั้นจะหาย ผู้เล่นที่มีลิงก์หรือรหัสสามารถเข้าห้องได้จนเต็ม
- ค่าเริ่มต้นคือเก็บคำอธิษฐานส่วนตัว ข้อความจะอยู่ในหน่วยความจำของแท็บที่เขียนเท่านั้น ชื่อเล่น แบบกระทง และคำอธิษฐานที่เลือกเปิดแชร์จะเห็นได้ในห้อง
- ใน **แนบรูปและ Instagram** เลือกรูป JPG, PNG หรือ WebP จากเครื่องและใส่ชื่อผู้ใช้หรือลิงก์โปรไฟล์ Instagram ได้ เบราว์เซอร์ย่อรูปก่อนส่งให้เพื่อนในห้อง ชื่อไอจีและรูปอยู่ในห้องระหว่างเล่นและเปิดได้จากกระทงแต่ละใบ
- ฉากหลักอยู่ใน `assets/river.webp` สร้างด้วย ImageGen จากบรีฟภาพทิวทัศน์สมจริงของแม่น้ำไทยยามค่ำ พระจันทร์เต็มดวง เงาวัดไทยริมฝั่ง แสงสีทองบนผิวน้ำ และพื้นที่โล่งสำหรับกระทง
- จังหวะกระทงแตะน้ำ วงน้ำ และแสงสะท้อน ใช้เหตุการณ์เดียวเป็นจุดเริ่มตามแนวคิดจาก [Lemo‑Opuscar](https://github.com/lemomo-ai/lemo-opuscar/blob/main/TECHNIQUE.md#3-one-timeline-drives-everything)
- ปุ่ม **เพลง** เปิดตัวเล่น YouTube ของเพลง [รอยกระทง (คิดฮอดเจ้าหลาย)](https://music.youtube.com/watch?v=B3oe2dZfm0M) โดยคณะขวัญใจ แต่ละคนกดเล่นหรือหยุดได้เอง หากตัวเล่นฝังเปิดไม่ได้ ให้ใช้ลิงก์ YouTube Music ใต้ตัวเล่น
